# Mikey for PC

The PC tray app, `mikeyd` (Rust), for Windows 10/11 and Linux. It exposes a virtual microphone and a virtual webcam fed by the phone.

Not started yet. The design is in [`vibe/brain/`](../vibe/brain/00-index.md) — start with the index, then the PC side of the architecture, the wire protocol and the PC tech stack.
