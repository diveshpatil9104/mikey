# Skill: Close a phase

**Use when:** the current phase's work looks done.

1. **Checklist.** Every box for the phase is ticked in [§ 18](../core/18-roadmap.md), and its *Done when* sentence is true.
2. **Real devices.** At least two phones (one Pixel/near-stock, one Samsung or Xiaomi) and one Windows + one Linux machine ([§ 18](../core/18-roadmap.md)), using the cases in [§ 19](../rules/19-test-matrix.md).
3. **Budgets.** Every number in [§ 15](../rules/15-performance-budgets.md) holds.
4. **Agent files.** Update *Current Phase* in AGENTS.md and CLAUDE.md, identically ([update-agent-files](update-agent-files.md)).
5. **Context.** Update `vibe/context.md` — status and next steps.
6. **Decisions.** Record anything that changed along the way in [§ 23](../core/23-open-decisions.md).
