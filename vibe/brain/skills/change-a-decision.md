# Skill: Change a decision

**Use when:** part of the plan turns out wrong, or the owner changes their mind.

The brain wins over code until it is deliberately updated — so update the brain first.

1. Edit the brain file that holds the decision.
2. If it is listed in [§ 23](../core/23-open-decisions.md), update the bold choice there.
3. If it touches the protocol, follow [change-the-protocol](change-the-protocol.md).
4. If it changes anything in AGENTS.md / CLAUDE.md, follow [update-agent-files](update-agent-files.md).
5. If the PC side is affected, let its owner know.
