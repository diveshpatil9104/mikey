# Skill: Close a phase

**Use when:** the current phase's work looks done.

1. **Checklist.** Every box for the phase is ticked in [roadmap.md](../core/roadmap.md), and its *Done when* sentence is true.
2. **Real devices.** At least two phones (one Pixel/near-stock, one Samsung or Xiaomi) and one Windows + one Linux machine ([roadmap.md](../core/roadmap.md)), using the cases in [test-matrix.md](../rules/test-matrix.md).
3. **Budgets.** Every number in [performance-budgets.md](../rules/performance-budgets.md) holds.
4. **Index & Roadmap.** Update [index.md](../index.md) (Current Status and next steps) and [roadmap.md](../core/roadmap.md) checklist — phases are tracked exclusively in `vibe/`.
5. **Decisions.** Record anything that changed along the way in [open-decisions.md](../core/open-decisions.md).
