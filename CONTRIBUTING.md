# Contributing to Mikey

A full guide will be written before v1.0. Until then:

- Read [`AGENTS.md`](AGENTS.md) and the project brain in [`vibe/brain/`](vibe/brain/00-index.md) first.
- Android: format with `ktlint`. PC: `rustfmt` and `clippy -D warnings`. Run them before committing.
- English everywhere — names, comments, commits.
- Don't add a dependency without discussing it first.
- `AGENTS.md` and `CLAUDE.md` must stay identical — edit one, copy it over the other.
